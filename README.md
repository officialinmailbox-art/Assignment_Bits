## 1. Project Overview

The objective of this project is to develop and evaluate machine learning classification models using the Adult Census Income Dataset.

The project predicts whether an individual's annual income is:

- **Greater than $50K (>50K)**
- **Less than or equal to $50K (<=50K)**

Five different machine learning classification algorithms are implemented and compared using standard evaluation metrics to identify the best-performing model.

---

## 2. Problem Statement

Income classification is an important machine learning application that uses demographic and employment-related information to predict an individual's income category.

The main objective is to build classification models that learn patterns from historical census data and predict whether an individual's income exceeds $50,000 per year.

The project focuses on:

1. Loading and understanding the dataset.
2. Cleaning and preprocessing the data.
3. Implementing five classification algorithms.
4. Evaluating model performance using multiple metrics.
5. Comparing the models and identifying the best-performing algorithm.
6. Saving trained models for future predictions.

## 4. Data Preprocessing

The following preprocessing operations were performed:

1. Loaded the dataset using Pandas.
2. Removed unnecessary spaces from column names and text values.
3. Replaced missing-value symbols (`?`) with null values.
4. Removed records containing missing values.
5. Converted the income target into binary numerical values.
6. Separated input features and target variable.
7. Identified numerical and categorical features.
8. Applied StandardScaler to numerical features.
9. Applied OneHotEncoder to categorical features.
10. Split the dataset into training and testing sets.

### Training and Testing Split

- Training Data: 80%
- Testing Data: 20%
- Random State: 42
- Stratified Sampling: Enabled

## 5. Machine Learning Algorithms

Five classification algorithms were implemented.

### 5.1 Logistic Regression

Logistic Regression is a supervised classification algorithm used to predict binary outcomes.

It provides a baseline model and identifies relationships between input features and income categories.

### 5.2 Decision Tree

Decision Tree is a tree-based classification algorithm that makes predictions using a sequence of decision rules.

It can identify non-linear patterns and is relatively easy to interpret.

**Configuration:** `max_depth=8`

### 5.3 K-Nearest Neighbours (KNN)

KNN is a distance-based classification algorithm that predicts the class using the nearest neighbouring data points.

**Configuration:** `n_neighbors=7`

### 5.4 Gaussian Naive Bayes

Gaussian Naive Bayes is a probabilistic classification algorithm based on Bayes' theorem.

It assumes conditional independence between features and models numerical features using Gaussian distributions.

### 5.5 Support Vector Machine (SVM)

Support Vector Machine identifies an optimal decision boundary between classes.

An RBF kernel is used to capture non-linear relationships.

**Configuration:** `kernel='rbf', C=1.0`

## 7. Observations on Model Performance

### Logistic Regression
- Provides a good baseline for income classification.
- Computationally efficient.
- Identifies linear relationships between features.
- May not capture complex non-linear patterns.

### Decision Tree
- Identifies non-linear relationships.
- Easy to understand and interpret.
- Maximum depth of 8 helps control overfitting.
- Performance depends on the selected tree depth.

### K-Nearest Neighbours (KNN)
- Uses seven nearest neighbours for classification.
- StandardScaler improves distance calculations.
- High-dimensional categorical features can affect performance.
- Prediction can be computationally expensive.

### Gaussian Naive Bayes
- Fast and computationally efficient.
- Uses probability-based classification.
- Assumes conditional independence between features.
- Gaussian assumptions may not accurately represent all dataset features.

### Support Vector Machine (SVM)
- Uses an RBF kernel to identify non-linear decision boundaries.
- Can provide good classification performance.
- Requires more computational resources for larger datasets.
- Performance depends on parameter selection.

## 8. Overall Best Model

The overall winning model is selected using the average of three evaluation metrics:

- AUC Score
- F1 Score
- Matthews Correlation Coefficient (MCC)

### Winner Selection Formula

Average Score = (AUC + F1 Score + MCC) / 3

The model with the highest average score is selected as the overall winner.
